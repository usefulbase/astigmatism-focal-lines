# 焦線と網膜

眼鏡店スタッフ向けに、乱視における焦線・網膜・補正レンズの関係を視覚的に学ぶための教育支援ツールです。

乱視の説明やスタッフ教育で、「度数を変えると焦線がどちらへ動くのか」「網膜に対して焦線がどこにあるのか」を直感的に確認できます。

## 公開ページ

https://usefulbase.github.io/astigmatism-focal-lines/astigmatism-focal-lines-D.html

## 主な機能

- 眼球断面図上で、網膜と焦線の位置関係を表示
- 水平方向・垂直方向の焦線を色分けして表示
- 焦線の中間位置を最小錯乱円として表示
- 焦線が重なったときは焦点として表示
- 焦点が網膜上に来たときに、図中でわかりやすく表示
- 目盛りの表示／非表示切り替え
- 図の拡大表示
- 入射光線のイメージ表示
- 補正レンズシミュレーション時に、凸レンズ・凹レンズによる光線の収束／発散イメージを表示
- 現在の目の状態を `S / C / AX` で設定
- `AX` は教育用に `180°` と `90°` に限定
- `S` と `C` は 0.25D 刻みで選択・連打入力
- 度数転換
- 正視へのリセット
- 補正レンズの `S / C` を手動調整
- クロスシリンダーの1番・2番・外す操作
- 必要なときだけ「補正レンズシミュレーション」「焦線を直接調整」を開く
- PC全画面、スマートフォン縦向き・横向きに対応
- PWA対応：ホーム画面に追加してアプリのように起動可能

## 基本的な使い方

1. 「現在の目の状態」で `S / C / AX` を設定します。
2. 図の中で、焦線と網膜の位置関係を確認します。
3. 必要に応じて「補正レンズシミュレーション」を開きます。
4. 補正レンズの `S / C` を手動で動かし、焦線や光線の変化を確認します。
5. クロスシリンダー練習では、1番・2番の見え方を比較しながら、ヒントを参考に円柱度数を調整します。
6. 図を直接動かして理解したい場合だけ、「焦線を直接調整」を開きます。

## クロスシリンダーについて

このツールでは、補正軸（AX）はすでに決定済みという前提で扱います。

そのため、クロスシリンダー練習では軸を動かさず、円柱度数（C）の比較・調整を中心に確認します。

教育用のため、円柱度数を動かした際の球面調整は自動では行いません。必要に応じて、`S` も手動で調整しながら練習します。

## スマホでアプリとして使う

公開ページを開き、ホーム画面に追加するとアプリのように起動できます。

- iPhone / iPad：Safari の共有ボタンから **ホーム画面に追加**
- Android：Chrome のメニューから **アプリをインストール** または **ホーム画面に追加**

初回は通信できる状態でページを開いてください。その後は、以前開いた内容をオフラインでも起動できます。

古い表示が残る場合は、ページの再読み込み、またはホーム画面のアプリを一度閉じて開き直してください。

## 注意

本ツールは、焦線・網膜・補正レンズの関係を理解しやすくするための教育用イメージです。

実際の屈折検査、処方判断、診断の代替には使用しません。
